# Schnupperkurs ECG 2026

PWA zur Verwaltung des Eishockey-Schnupperkurses.

## Features

- ✅ Kinderliste mit CSV-Import/Export
- ✅ Schlittschuh-Verwaltung
- ✅ Trainingstermine mit Anwesenheit
- ✅ Foto-Upload für alle
- ✅ E-Mail-Verwaltung
- ✅ Passwort-Manager
- ✅ Echtzeit-Sync über Supabase
- ✅ Dark/Light Mode
- ✅ Installierbar als PWA

## Installation

1. Supabase-Projekt erstellen
2. SQL ausführen (Tabellen erstellen)
3. Supabase URL und Key in `index.html` eintragen
4. Auf GitHub Pages deployen

## Deployment auf GitHub Pages

1. Repository erstellen
2. Dateien hochladen
3. Settings → Pages → Source: main branch
4. Fertig!
